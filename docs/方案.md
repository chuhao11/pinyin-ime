# 拼音输入法方案

自用的 Windows 11 拼音输入法。只给自己用，不考虑大众化。这份文档记录已经定下的设计，改设计时同步改这里。

## 总体

- 语言：Rust。
- 结构：
  - 每个程序里只放一个很薄的输入法 DLL（Windows TSF），只负责转发按键、把字上屏。
  - 引擎是单独的进程，**完全不联网**：拼音切分、查词、排序、记忆、纠错、候选窗都在这里。
  - 唯一能联网的是热词更新器：只下载签过名的纯文本词表，不上传任何东西，不下载代码。
- 全部用 CPU，显存 0。内存目标：引擎 100–250 MB，每个程序里的 DLL 1–2 MB。
- 长期运行内存不能膨胀：
  - 词库和模型只读、大小固定。
  - 用户词库有条数上限（10 万条），满了淘汰很久没用、用得少的。
  - 所有缓存有固定容量；不保存打字记录；日志有大小上限。
  - 有"连续打几十万个键"的内存测试。
  - Windows 上引擎超过内存上限会自己重启。

## 按键规则

| 按键 | 没在打字 | 候选条 | 5×5 矩阵 |
|---|---|---|---|
| 字母 | 开始输入（Caps Lock 开着时直接大写上屏） | 继续输入 | 收起矩阵，继续输入 |
| Shift+字母 | 大写字母进入输入串 | 同左 | 同左 |
| 数字 1–8 | 原样输出 | 选对应的候选 | 1–5 选高亮那一行的候选（只有高亮那一行标数字） |
| 空格 | 原样输出 | 上屏高亮的候选（默认第一个） | 上屏高亮的候选 |
| ← → | 交给程序 | 在候选条里移动高亮 | 移动高亮 |
| ↑ ↓ | 交给程序 | 不做事 | 上下移动；最后一行再按 ↓ 换下一批 25 个 |
| `-` | 原样输出 | 打开矩阵 | 收起矩阵 |
| `=` 和其他所有符号 | 原样输出，跟英文键盘一样 | 先上屏高亮的候选，再输出符号 | 同左 |
| 回车 | 原样 | 把已选的字 + 打的字母原样上屏 | 同左 |
| Esc | 原样 | 清空输入 | 收起矩阵 |
| 退格 | 原样 | 删一个字母；字母删完再按，撤销上一次选字 | 收起矩阵，删一个字母 |
| 单按 Shift | 切换中文 / 纯英文 | 先把打的字母原样上屏，再切到纯英文 | 同左 |

- 没有中文标点模式，所有符号都是英文半角。
- 空格永远是英文半角空格，不会出现全角空格（Word 里中文输入法打出的"大空格"）；也没有全角字母、数字。
- 纯英文模式（单按 Shift 进入，再按一下回来）：所有键原样交给程序，不出候选。Shift+字母仍然是大写，不会切换。
  （试打工具里收不到"单按 Shift"，用 Tab 代替。）
- 分隔符 `'` 保留，但尽量用不到：西安、方案/反感这类不同切法直接混在候选里。

## 候选和排序

- 候选条显示 4–8 个，按长度灵活决定：单字多显示，三四字词少显示；后面质量太差的不硬凑。
- 支持全拼、简拼（`zg`→中国）、混拼（`zhongg`）。
- 分数 = 使用频率 + 字的等级 + 你的记忆：
  - 字的等级按《通用规范汉字表》：一级 > 二级 > 三级 > 表外；繁体不出；频率接近时笔画少的在前。
  - 表外字：用量很低的直接删（如"鯙"），在词里有一定用量的保留在词里；清单见 `docs/表外字清单.md`。
- 记忆：
  - 词和人名选一次就排第一；随时间慢慢淡化（半衰期 90 天）。
  - 单字记得很慢：同一个拼音一直选同一个字，要选几十次才会换到第一位（偶尔选一次"事"，"是"不会掉下去）。
  - 分几次选字拼出来的词，自动存成新词。
  - 单字的顺序：70% 看"单独打这个字有多常见"（语言模型统计），30% 看词库里的总频率。
    所以只打一个 `l` 是"了"、`n` 是"你"、`h` 是"和"。
- 不做联想，不预测下一个词；也不"多猜字母"：末尾已经是完整音节时不往后猜（`zheba` 不出"这般"）。
- 不常用的整词（比如 `nihao` 的"拟好"）排在常用单字后面，不占候选条。
- 词库里没有的搭配（好+胀）也会给出：整句保留多种拼法，接近的放前面，其余放在矩阵里。
- 首选的多字词你一直不选、总选别的：冷落满 3 次就删掉它（单字不删）。
- 不过滤粗口和露骨的词，不在这方面偏心。

## 语言模型

- 二元模型：统计"每个词后面跟另一个词"的概率，整句转换时看相邻两个词的搭配（吧/把、的/得/地 这类）。
- 语料（只在 Mac 上用来生成模型，不进安装包，用完可删）：
  - LCCC 对话语料（清华，网上真人聊天，579 MB）：口语、语气词、网络说法。
  - 中文维基百科（2026-11-01 版，3.45 GB）：书面语、人名地名。
- 生成：
  - 日常：`cargo run --release -p lmgen -- build --lccc data/raw/corpus/lccc_large.jsonl.gz --wiki data/raw/corpus/zhwiki-20261101-pages-articles.xml.bz2`
  - 书面：同上，再加 `--chat-weight 1 --wiki-weight 3 --max-bigrams 20000000 --out data/build/pinyin-formal.lm`
  - 每段话前面加"<句首>"（数字后面的加"<数字>"），整句转换没有上文时从"<句首>"开始。用输入法自己的词库切词；
  单词概率 = 0.8 × 语料频率 + 0.2 × 词库原权重；搭配用绝对折扣插值，只留常见搭配；语料里出现不到 2 次的词不进模型词表（用词库分数换算）。
- 每 200 条语料留一条不参加统计，生成 `crates/engine/tests/eval_sentences.tsv`，测整句转换准确率（有模型 vs 没模型）。
- 上文：刚上屏的最后一个词（30 秒内、中间没有按别的键）当作下一次输入的上文。只在内存里，不保存。
- 两种模式，在设置里选（试打工具里按 Ctrl+T）：
  - **日常**（`pinyin.lm`）：对话语料次数 ×3，适合聊天、发消息。默认。
  - **书面**（`pinyin-formal.lm`）：维基百科次数 ×3，适合写文章、报告。
  - 同一时间只加载一套；记住的词、打错习惯两种模式共用。
- 多音字：语言模型按文字统计，分不出读音，所以再乘上"这个读音占这个字所有读音的比例"（来自词库），"呢"读 ni 不会排前面。
- 繁转简只转成常用字（避免 綫→缐）。
- 数字也算上文：紧跟在数字后面的字（"2010年"的"年"、"5月"的"月"）单独统计，
  所以打了 2010 再打 `n` 是"年"，单独打 `n` 还是"你"。
- 不预测下一个词，只用来给正在打的拼音挑对字。

## 打错纠正

- 能纠正：按到旁边的键、两个字母打反（包括跨两个音节，`zhdiao`→知道）、漏打一个、多打一个。
- 纠正要扣分：你打的本来就是能用的拼音时扣得更多；纠正出来的候选只有比"不纠正"的所有读法都好时才放前面，
  所以 `haozhang` 不会被改成"保障"，`woxuhuan` 会给出"我喜欢"。纠正出来的候选带一个小标记。
- 记住你的错法：
  - 选了一次纠正结果，以后一模一样的错直接排第一（`xuwang` 选过"希望"，下次第一个就是"希望"）。
  - 同时记住"你容易把 u 打成 i"这类规律，别的词里同样的错扣分变少。

## 英文

- 词表：雾凇拼音英文词库（约 2.2 万常用词 + 缩写/互联网词），按 Google 万亿词语料的频率排序。
- 能对上：完全一样、补全当前这个词（不预测下一个词）、拼写纠错（`recieve`→receive）。
- 排序：按分数和中文混排。输入本身就是完整拼音时（`you`、`women`）中文在前；拼不成拼音的（`help`、`what`）英文在前。
- 输入拼不成拼音（或者有大写字母）时，原样的字母永远是第一个。
- 跟着你打的大小写：`Help` → Helpful；全大写 → 全大写。
- 用过的英文词（包括词表里没有的，比如 kubernetes）会记住，下次补全、纠错都能找到。

## 数据来源

- 词库：雾凇拼音（iDvel/rime-ice），固定版本，见 `tools/fetch-data.sh`。
- 英文：雾凇拼音英文词库 + google-10000-english 的 20k 频率表。
- 字的等级、笔画：Unicode Unihan 18.0（kTGH、kTotalStrokes）。

## 阶段

1. 引擎核心（Mac 上开发测试）：拼音切分、词库、排序、记忆、按键规则、试打工具。
2. Windows 外壳：TSF DLL + 引擎进程 + 候选窗。GitHub 自动编译安装包，拷到 Windows 电脑上测。
3. 词网 + n-gram 语言模型（整句）。（已提前做完，2026-11-20）
4. 打错容错 + 学习打错习惯；英文单词候选和拼写纠错。（已提前做完基本版，2026-11-20）
5. 热词更新（签名数据）+ 安全加固 + 安装包。
6. （可选）小神经网络重排、设置界面。

## 安全

- 引擎和 DLL 不链接任何网络库，编译时自动检查。
- 没有云输入、统计上报、广告、插件或脚本系统。
- 更新器只更新数据，程序只能手动升级。
- 进程间管道只允许本机本人；DLL 核对引擎身份。
- 密码框里停用；登录界面和 UAC 弹窗里不加载。
- 用户词库只存本机，只保存词和次数，不保存打字记录。
