# 拼音输入法方案

自用的 Windows 11 拼音输入法。只给自己用，不考虑大众化。这份文档记录已经定下的设计，改设计时同步改这里。

## 总体

- 语言：Rust。
- 结构：
  - 每个程序里只放一个很薄的输入法 DLL（Windows TSF），只负责转发按键、把字上屏。
  - 引擎是单独的进程，**完全不联网**：拼音切分、查词、排序、记忆、纠错、候选窗都在这里。
  - 唯一能联网的是热词更新器：只下载签过名的纯文本词表，不上传任何东西，不下载代码。
- 全部用 CPU，显存 0。内存目标：引擎 100–250 MB，每个程序里的 DLL 1–2 MB。
- 长期运行内存不能膨胀：
  - 词库和模型只读、大小固定。
  - 用户词库有条数上限（10 万条），满了淘汰很久没用、用得少的。
  - 所有缓存有固定容量；不保存打字记录；日志有大小上限。
  - 有"连续打几十万个键"的内存测试。
  - Windows 上引擎超过内存上限会自己重启。

## 按键规则

| 按键 | 没在打字 | 候选条 | 5×5 矩阵 |
|---|---|---|---|
| 字母 | 开始输入（Caps Lock 开着时直接大写上屏） | 继续输入 | 收起矩阵，继续输入 |
| Shift+字母 | 大写字母进入输入串 | 同左 | 同左 |
| 数字 1–8 | 原样输出 | 选对应的候选 | 1–5 选高亮那一行的候选（只有高亮那一行标数字） |
| 空格 | 原样输出 | 上屏高亮的候选（默认第一个） | 上屏高亮的候选 |
| ← → | 交给程序 | 在候选条里移动高亮 | 移动高亮 |
| ↑ ↓ | 交给程序 | 不做事 | 上下移动；最后一行再按 ↓ 换下一批 25 个 |
| `-` | 原样输出 | 打开矩阵 | 收起矩阵 |
| `=` 和其他所有符号 | 原样输出，跟英文键盘一样 | 先上屏高亮的候选，再输出符号 | 同左 |
| 回车 | 原样 | 把已选的字 + 打的字母原样上屏 | 和空格一样：上屏高亮的候选 |
| Esc | 原样 | 清空输入 | 收起矩阵 |
| 退格 | 原样 | 删一个字母；字母删完再按，撤销上一次选字 | 收起矩阵，删一个字母 |
| 单按 Shift | 切换中文 / 纯英文 | 先把打的字母原样上屏，再切到纯英文 | 同左 |
| `` ` ``（数字 1 左边） | 原样输出（中文标点开着时是 ·） | 第一下：高亮的词变成彩虹色；第二下：删掉这个词，以后再也不出现 | 同左 |

- 中文标点：设置里的开关，**全有或全无**。
  - 关（默认）：所有符号永远是英文半角，跟英文键盘一样。
  - 开：所有符号永远是中文标点，数字后面也一样（打 `3.` 得到"3。"）：
    `, . ? ! : ;` → `， 。 ？ ！ ： ；`，`( ) [ ] { } < >` → `（ ） 【 】 ｛ ｝ 《 》`，
    `\` → `、`，`^` → `……`，`_` → `——`，`$` → `￥`，`~` → `～`，`` ` `` → `·`，
    `"` 和 `'` 自动左右交替（“ ” ‘ ’）。
  - 小键盘上的 `. + - * /` 和数字永远原样输入（小键盘打 1.5 不会变成"1。5"，小键盘的减号也不会打开矩阵）。
  - `-` 和 `=` 两种模式下都不变（`-` 在打字时打开矩阵）。
- Ctrl / Alt / Win 组合键永远交给程序；正在打拼音时按了快捷键，先把打的字母原样上屏，再执行快捷键。
- 空格永远是英文半角空格，不会出现全角空格（Word 里中文输入法打出的"大空格"）；也没有全角字母、数字。
- 纯英文模式（单按 Shift 进入，再按一下回来）：所有键原样交给程序，不出候选。Shift+字母仍然是大写，不会切换。
  （试打工具里收不到"单按 Shift"，用 Tab 代替。）
- 分隔符 `'` 保留，但尽量用不到：西安、方案/反感这类不同切法直接混在候选里。

## 候选和排序

- 候选条显示 4–8 个，按长度灵活决定：单字多显示，三四字词少显示；后面质量太差的不硬凑。
- 支持全拼、简拼（`zg`→中国）、混拼（`zhongg`）。
- 分数 = 使用频率 + 字的等级 + 你的记忆：
  - 字的等级按《通用规范汉字表》：一级 > 二级 > 三级 > 表外；繁体不出；频率接近时笔画少的在前。
  - 表外字：用量很低的直接删（如"鯙"），在词里有一定用量的保留在词里；清单见 `docs/表外字清单.md`。
- 记忆：
  - 人名、菜名这种没有常用竞争对手的词：选一次就排第一。
  - 和很常用的词抢位置的冷门词（`shiqing` 的"世情"）：选一次放进前 4 个，第一个仍是"事情"；选三次左右才排第一。
  - 单字记得更慢：同一个拼音一直选同一个字，要选二十多次才会换到第一位。
  - 上次选过、但排在第 4 个以后的字词（60 天内）：下次放到第 4 个，候选条里一眼能看到。
  - 记忆随时间慢慢淡化（半衰期 90 天）：久不用的往后排，但不删。
  - 分几次选字拼出来的词，自动存成新词。
  - 人名（词库里没有、以常见姓氏开头、前两个字本身不是词）：不随时间变淡，记忆库满了也不删（最多占容量的一半）。
  - 只有这几类按时间真正删除：拼起来的短语（不是人名、不是你加的）只用过一次、半年没再用；
    搭配记忆一年没再出现；"首选被冷落"一个月内没凑满 3 次就清零。
  - 设置页"添加词语"加的词：用全拼打时排第二个；之后和别的词一样，选得多排第一，久不用慢慢往后。
  - 单字的顺序：70% 看"单独打这个字有多常见"（语言模型统计），30% 看词库里的总频率。
    所以只打一个 `l` 是"了"、`n` 是"你"、`h` 是"和"。
- 不做联想，不预测下一个词；也不"多猜字母"：末尾已经是完整音节时不往后猜（`zheba` 不出"这般"）。
- 不常用的整词（比如 `nihao` 的"拟好"）排在常用单字后面，不占候选条。
- 词库里没有的搭配（好+胀）也会给出：整句保留多种拼法，接近的放前面，其余放在矩阵里。
- 首选的多字词你一直不选、总选别的：一个月内冷落满 3 次就删掉它（单字不删）。
- 多字词的分数：一半看语言模型，一半看词库里的使用频率。语言模型的语料里有维基百科，
  百科里多、平时少用的词（犬种、西接、游戏角色名）会被抬高；词库频率来自很广的语料，两边各一半比较中性——
  不刻意口语，也不刻意书面，股票、专业词照样靠前（看盘、个股、市盈率、量化）。
- 几个单字拼出来的组合（坎潘、张廷）：有一个真正的词能对上整串时，排在它后面。
- 个别词的调整（`crates/engine/src/adjust.tsv`）：正常的粗口排在网上避讳的写法前面（妈的 在 码的、尼玛 前面）；
  很老的谐音梗往后排（杯具、神马、鸭梨）；地理描述往后排（"东西南北 + 街/门/站/接/临……"：西街、西接、北站）。
- 不过滤粗口和露骨的词，不在这方面偏心。

## 语言模型

- 二元模型：统计"每个词后面跟另一个词"的概率，整句转换时看相邻两个词的搭配（吧/把、的/得/地 这类）。
- 语料（只在 Mac 上用来生成模型，不进安装包，用完可删）：
  - LCCC 对话语料（清华，网上真人聊天，579 MB）：口语、语气词、网络说法。
  - 中文维基百科（2026-11-01 版，3.45 GB）：书面语、人名地名。
- 生成：
  - `cargo run --release -p lmgen -- build --lccc data/raw/corpus/lccc_large.jsonl.gz --wiki data/raw/corpus/zhwiki-20261101-pages-articles.xml.bz2`
  - 每段话前面加"<句首>"（数字后面的加"<数字>"），整句转换没有上文时从"<句首>"开始。用输入法自己的词库切词；
  单词概率 = 0.8 × 语料频率 + 0.2 × 词库原权重；搭配用绝对折扣插值，只留常见搭配；语料里出现不到 2 次的词不进模型词表（用词库分数换算）。
- 每 200 条语料留一条不参加统计，生成 `crates/engine/tests/eval_sentences.tsv`，测整句转换准确率（有模型 vs 没模型）。
- 上文（前后词关联）：刚上屏的最后一个词（30 秒内、中间没有按别的键）当作下一次输入的上文。
  - 上一个词和这个字词连起来本身是一个词（谢+谢、吃+饭、走+吧）：这个字词加分，最可靠。
  - 统计里真的常一起出现（前一个词后面接它的概率 ≥ 5%，比如 数字→年）：按搭配加分，最多 +3。
  - 统计里只是偶尔一起出现：最多 +1（单字）/ +1.5（词）。统计里没见过的不扣分。
  - 连起来是词时，这个字在这里的读音必须是常见读音（打 di 时不因为"他的"给"的"加分）。
  - 所以上文只能微调，不会让一个不相干的字突然排第一（以前打完"滚"再打 gun，"棍"会排第一）。
  - 记住你自己的搭配：在某个上文后面你选了什么，下次同样的上文就优先它（选一次就生效）。
    最多记 2 万条，满了淘汰最久不用的；和词语记忆一样只存本机。
- 打的正好是一个完整音节（gun、lin、ban、xian）：前 3 个是这个音的常用单字，然后才是词。
  - 把完整音节拆开的简拼（gu+n=姑娘、li+n=理念、ba+n=八年）额外扣分。
  - 你经常打的词例外（用过 2 次以上），可以排在单字前面。
- 打一个完整音节时，单字后面的第一个位置留给全拼对上的词（`xian` → 先 县 现 西安），只要它和第三个单字差得不多。
- 单字"几十次就改"：一个字你选了 20 次以上、而且比现在排第一的字多选一半以上，它就排第一。
- 只有一个模型（`pinyin.lm`，对话语料次数 ×3 + 维基）。以前的"日常 / 书面"两种文风已经取消（2026-11-21）。
- 多音字：语言模型按文字统计，分不出读音，所以再乘上"这个读音占这个字所有读音的比例"（来自词库），"呢"读 ni 不会排前面。
- 繁转简只转成常用字（避免 綫→缐）。
- 数字也算上文：紧跟在数字后面的字（"2010年"的"年"、"5月"的"月"）单独统计，
  所以打了 2010 再打 `n` 是"年"，单独打 `n` 还是"你"。
- 不预测下一个词，只用来给正在打的拼音挑对字。

## 打错纠正

- 能纠正：按到旁边的键、两个字母打反（包括跨两个音节，`zhdiao`→知道）、漏打一个、多打一个。
- 纠正要扣分：你打的本来就是能用的拼音时扣得更多；纠正出来的候选只有比"不纠正"的所有读法都好时才放前面，
  所以 `haozhang` 不会被改成"保障"，`woxuhuan` 会给出"我喜欢"。纠正出来的候选带一个小标记。
- 你打的原样拼写本身就有常用的词时（`zheye` → 这也），纠错的（这个）要比它好很多才排第一，否则放第二个。
- 纠错的排在前面、你却选了别的（原样拼写的、英文、原样字母）：记住"这样打不是打错"，以后这个纠错不再排前面。
- 前后鼻音打混（in/ing、en/eng、an/ang、ian/iang、uan/uang）：扣分比别的打错轻；
  原样拼写有常用词时，最常用的两个放在第 5、6 个（禁止 打成 `jingzhi` 也能在候选条里看到）；
  原样拼写没有像样的词时（`wengti`）直接排第一（问题）。只用在多字词里。
- 记住你的错法：
  - 选了一次纠正结果，以后一模一样的错直接排第一（`xuwang` 选过"希望"，下次第一个就是"希望"）。
  - 同时记住"你容易把 u 打成 i"这类规律，别的词里同样的错扣分变少。

## 英文

- 词表：雾凇拼音英文词库（约 2.2 万常用词 + 缩写/互联网词），按 Google 万亿词语料的频率排序。
- 能对上：完全一样、补全当前这个词（不预测下一个词）、拼写纠错（`recieve`→receive）。
- 排序：按分数和中文混排。输入本身就是完整拼音时（`you`、`women`）中文在前；拼不成拼音的（`help`、`what`）英文在前。
- 输入拼不成拼音（或者有大写字母）时，原样的字母永远是第一个。
- 跟着你打的大小写：`Help` → Helpful；全大写 → 全大写。
- 用过的英文词（包括词表里没有的，比如 kubernetes）会记住，下次补全、纠错都能找到。

## 数据来源

- 词库：雾凇拼音（iDvel/rime-ice），固定版本，见 `tools/fetch-data.sh`。
- 英文：雾凇拼音英文词库 + google-10000-english 的 20k 频率表。
- 字的等级、笔画：Unicode Unihan 18.0（kTGH、kTotalStrokes）。

## Windows 外壳

| 部分 | 文件 | 说明 |
|---|---|---|
| 输入法 DLL | `pinyin-tsf64.dll`、`pinyin-tsf32.dll` | 加载进每个程序（64 位、32 位各一个）；只转发按键、写字、画候选窗 |
| 引擎 | `pinyin-engine.exe` | 登录时自动启动，后台运行，没有窗口；词库、模型、记忆都在这里 |
| 设置页 | `pinyin-settings.exe` | 桌面快捷方式"拼音输入法设置"：中文标点开关、添加词语 |
| 数据 | `data\pinyin.dict, pinyin.lm, english.tsv` | 只读，按需读入内存（不会一下子占几百 MB） |
| 你的记忆、设置 | `%APPDATA%\PinyinIME` | 只有你能读写；卸载时保留；**不会**从别的电脑带过来 |

- 候选窗：只在打字时出现，贴着正在打的字（下面放不下就放上面，不跑出屏幕）；
  圆角、淡阴影，跟随 Windows 深色/浅色；高亮的候选是朱红色圆角块（和图标的印章同色）；
  第一行小字是正在打的拼音；打错纠正出来的候选后面带一个小 `~`。
  不抢焦点、不进任务栏和 Alt+Tab，点它也不会让程序失去焦点。
- 单按 Shift 切换中英后，光标旁边闪 0.7 秒"中"或"英"，然后自己消失。
- 设置页改了立即保存、立即生效（引擎两秒内也会自己发现）；软件渲染，关掉就退出。
- 删词：高亮一个不想要的词，按两下 `。第一下它变成彩虹色、候选窗顶上提示"再按一次删除"，按别的键取消；
  第二下删掉，这个读音下（全拼、简拼都算）再也不出现。能删两个字以上的词，包括单字拼出来的组合（坎潘）；
  单字、英文不删。删错了在"添加词语"里加回来就恢复。
- 设置页有一块"小技巧"，写着这些和别的输入法不一样的用法（单按 Shift、- 矩阵、回车、按两下 ` 删词……）。
- 设置页"添加词语"：多行输入框，词语之间用任意标点、空格、换行隔开；多音字可以写成 `银行(yin hang)`。
  点"加入"交给引擎，马上能用；跳过的词（有字母数字、单个字、太长、拼音对不上）留在输入框里，改了可以再加。
  引擎没在运行时先存进 `%APPDATA%\PinyinIME\pending_words.txt`，引擎启动时自动加入。
- 安装：GitHub 自动编译出 `PinyinIME-Setup-x.y.z.exe`，拷到 Windows 上双击安装（要管理员权限，因为输入法要在系统里登记）。
  装完自动加进你的输入法列表（不改默认输入法），按 Win+空格 切到"拼音"。

## 和别的程序不冲突

输入法 DLL 会被加载进几乎每个程序，规矩是"拿不准就放过"：

| 情况 | 做法 |
|---|---|
| 没在打字 | 什么窗口都不出（不像有的输入法开机就弹状态栏） |
| Ctrl / Alt / Win 组合键 | 没在打字时一律交给程序；在打字时先把字母原样上屏再交给程序 |
| 功能键 F1–F24、音量和媒体键、截屏、菜单键、别的程序模拟输入的字符 | 任何时候都交给程序（打字打到一半也能调音量、F5 刷新） |
| 空格、方向键、回车、退格、Tab、Home 等 | 只有屏幕上正在打拼音时才归输入法；没在打字时一律交给程序 |
| 单独按 Shift | 只有"按下后 0.8 秒内松开、中间没按别的键、没点鼠标"才算切换（系统的保留键检测 + 自己的检测，谁先报都只切一次）；Shift+点鼠标选文字、Ctrl+Shift、Alt+Shift 都不算；Shift 松开永远交给程序（包括系统检测到的那一次，游戏里不会以为 Shift 一直按着） |
| 密码框、PIN、纯数字框 | 不工作（按输入框声明的类型判断） |
| 只读区域、没有输入框、程序禁用了输入法（很多游戏、老式密码框这样做）、按 Ctrl+空格 关掉了输入法 | 不工作 |
| 全屏游戏（全屏且不是正常的文字输入框） | 默认按键全交给游戏，WASD 不会变成打字；要在游戏里聊天，单按 Shift 临时打开中文，回车发出去或 Esc 关掉后自动恢复 |
| 按下和松开 | 成对处理：程序收到了一个键的按下，就一定收到它的松开；按下被输入法用掉的键，松开也用掉。按住不放（系统连发按下）只记一次。不同程序问输入法的方式不一样（先问再处理、不问直接处理、问好几遍），每次按键都只判断一次。以前这里出过错：没配对的"松开"被吃掉，B 站以为方向键一直按着就开了倍速、空格暂停不了 |
| 开始不了输入的地方（网页上没有输入框的地方，比如在看视频；不接受文字的控件） | 试着开始输入失败，马上清掉引擎里的拼音、这个键还给程序，并记住这个地方（换了输入框再重新试）。绝不会出现"屏幕上什么都没有，空格、方向键却被输入法拿走" |
| 引擎没运行、卡住、版本不对 | 每次最多等 0.3 秒，然后按键原样交给程序；引擎没运行就帮忙启动一次（管理员权限的程序、商店应用沙箱里不启动） |
| 程序把输入打断（点了别处、换了输入框） | 已经打的字母留在原处，清空状态，候选窗收起 |
| DLL 里任何错误 | 全部兜住，绝不让程序崩溃；不依赖 VC++ 运行库（新装的 Windows 也能加载） |
| 登录界面、UAC 弹窗 | 不加载 |
| 内存 | 每个程序里只多一个很小的 DLL；候选窗用软件渲染，不往每个程序里加载显卡驱动 |

已知限制：
- 带内核反作弊的网游（比如 Valorant、部分腾讯游戏）可能不喜欢没有数字签名的 DLL 进入游戏进程。
  玩这类游戏前按 Win+空格 切到"英语"键盘，这个输入法就根本不会加载进游戏。
- 有的老程序（DPI 不感知的）里候选窗会稍微模糊，这是 Windows 对这类程序的统一缩放。

## 安全

- 引擎和 DLL 不链接任何网络库，编译时自动检查。
- 没有云输入、统计上报、广告、插件或脚本系统。
- 更新器只更新数据，程序只能手动升级。
- 进程间管道只允许本机本人；DLL 核对引擎身份。
- 密码框、PIN 框里停用；登录界面和 UAC 弹窗里不加载。
- 引擎只以普通权限运行：管理员程序、沙箱程序里的 DLL 不会去启动引擎（启动出来的引擎权限不对）。
- 用户词库只存本机，只保存词和次数，不保存打字记录。
